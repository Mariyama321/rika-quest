# 理科クエスト

理科・社会の単元をモンスター冒険で復習する学習ゲーム。

- サイト: GitHub Pages で公開
- 地図データ: [@svg-maps/japan](https://github.com/VictorCazanave/svg-maps)（Victor Cazanave, CC BY 4.0）をもとに作成

## さくせんボード（keikaku/）
- なお用の「やる日」を決める計画アプリ。https://mariyama321.github.io/rika-quest/keikaku/
- keikaku/tasks.json は「なおの勉強手帳」から予約タスクが毎日作り直す（tools/build_tasks.py）。名前などの個人情報は入れない
- スターや計画の記録は端末の localStorage（sakusenBoard_v1）にだけ保存
